# Power Electronics

Lab coursework and project for *Power Electronics*, KU Leuven (Campus Group T) — Master's in Electronics-ICT Engineering Technology. The labs are hands-on: build the circuit on a breadboard, characterize it with a bench power supply and oscilloscope, and report the measured behavior against the theoretical prediction.

## Labs

| Lab | Topic | Status |
|---|---|---|
| [`lab-1`](./lab-1) | Thyristor, TRIAC, MOSFET/IGBT switching & clamping circuits | Done |
| [`lab-3`](./lab-3) | Charge pump power supplies (LT1054) & step-down converter (LM2575) | Done |
